RaidMinus — минусы и плюсы от РЛа за рейд (WoW 3.3.5a, ЦЛК 25)
==================================================================

Итог ролла лута = /roll (1–100) + сумма минусов и плюсов игрока за рейд.

УСТАНОВКА
  Папку RaidMinus положить в Interface\AddOns. Желательно, чтобы стояли DBM (пул и убийство
  босса) и Skada (планка ДПС, бонус Профа). Без них аддон работает, но эти функции не сработают.

КАК ПОЛЬЗОВАТЬСЯ
  /rm — окно, «Начать рейд».

  Минусы     — клик по игроку (Ctrl — несколько, Shift — весь класс, ПКМ — роль),
               затем клик по правилу. Внизу — свой минус с причиной и «Отменить последнее».
  Правила    — кнопка «Правила»: свои правила по боссам, очки, «кик».
               Цвет метки: красная — автоматика, оранжевая — видно, кто нарушил,
               белая — решаете вы. ПКМ по правилу в окне — включить / выключить.
  Автоматика — 17 встроенных правил ловятся сами (журнал боя, DBM, Skada), по умолчанию -10.
               Находки — во вкладке «На проверку» (галочка — поставить, крест — отклонить).
               «Ставить сразу» у правила — минус игроку без проверки.
  Журнал     — снять минус с причиной (для споров) или вернуть.
  Розыгрыш   — добыча собирается сама (что залутали; окошко «Добыча» при открытии тела;
               ролл, объявленный ответственным за добычу). «Начать ролл» → «Закончить розыгрыш»:
               итог в рейд, каждый игрок отдельной строкой, победитель со звездой.
               Есть «Ролл на офф-спек».
  Игроки     — шепчут вам !минус и получают свою сумму и список.

ПОРЕПЕТИРОВАТЬ ДО РЕЙДА
  /rm тест — тестовый рейд из 25 выдуманных игроков, в чат ничего не уходит.
  «Тест: босс» — убийство следующего босса: автоматика, шёпот, добыча.
  «Тест: чужой ролл» — ролл, объявленный ответственным за добычу.

КОМАНДЫ
  /rm старт | конец | правила | настройки | помощь
  /rm Имя -20 причина     — свой минус (или +10 — плюс)
  /rm ролл [предмет]      — разыграть (shift+клик по предмету)

ВАЖНО
  WoW записывает данные аддонов на диск только при /reload и выходе. После убийства босса аддон
  предложит /reload, чтобы при вылете игры журнал рейда не пропал.
