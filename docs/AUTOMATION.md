# RaidMinus — триггеры правил (ЦЛК 25)

С 0.4.0 встроенной автоматики нет. У любого правила свода может быть **триггер с условиями** — как в
WeakAuras, только внутри RaidMinus (вкладка «Правила» → подвкладки «Триггер» и «Условия»). Включённый
триггер сам ставит минус (или плюс) виноватому — сразу, с записью в чат «триггер: Вася −30 (Дух) — что
было»; ошибку снимают во вкладке «Журнал». Без триггера правило ставит только РЛ.

Код: `Triggers.lua` (движок), `Pull.lua` (пулл-таймер DBM), `Data/Presets.lua` (шаблоны и неудачи LibFail),
`UI/RulesTab.lua` (редактор).

## Когда работают

В бою с боссом — от пула DBM до убийства или вайпа: правила раздела этого босса и раздел «Общие».
«Skada после убийства» и событие `RM_SKADA` — сразу после убийства. В тестовом рейде журнала боя нет:
«Тест: босс» сам «срабатывает» включённые триггеры на подходящих выдуманных игроках (с условиями).

## Типы

| Тип | Поля | Кто виноват |
|---|---|---|
| Неудача (Skada) | неудача LibFail (список ЦЛК по боссу раздела, в «Общих» — все) | кого назвал LibFail |
| Журнал боя | событие: урон / попадание (урон или промах) / наложена аура / применение / начало произнесения / призыв / прерывание / рассеивание; заклинание (номера или названия через запятую, пусто — любое); от кого (NPC ID или имя); урон от N; серия дольше N сек (удары не реже раза в 2 сек) | цель или источник (питомец → хозяин); игрок рейда |
| Смерть | последний удар (заклинание, пусто — любая смерть), от кого | умерший или убийца (игрок рейда — МК) |
| Аура | аура, стаков от N, держится дольше N сек | носитель |
| Сообщение босса | текст содержит… (крик, эмоция, шёпот босса) | игрок, чьё имя в сообщении; шёпот босса — я |
| DBM: пул раньше таймера | раньше на N сек | первый, кто тронул босса (урон, дебафф, таунт; питомец — хозяин) |
| Skada после убийства | ДПС / урон / урон по цели (имена или NPC ID), меньше или не меньше N | каждый подходящий игрок |
| Свой код (Lua) | события + `function(event, ...) return "Имя", "что было" end` | кого вернул код или `RM.Fire` |

**Смерть** = удар с перебором здоровья (overkill > 0) по игроку рейда. Причину видно, только если событие
дошло до журнала боя: на Кораблях и у Валитрии часть событий не доходит.

## Условия

- **С какого раза** — N-й раз за бой у одного игрока (пусто — с первого).
- **Не чаще** — каждый раз (тому же игроку не чаще раза в 5 сек) / раз за бой (по умолчанию) / раз за рейд.
  Считаются записи журнала — переживают /reload; снятый минус можно поставить снова.
- **Сложность** — любая / только гер. / только об.
- **Роль виновного** — по основной роли на рейд (хил, переодетый в ДД, — хил). Все включены — любая.

## Свой код

Строка кода — выражение-функция, как «Custom» в WeakAuras:

```lua
function(event, _, sub, _, srcName, _, _, dstName, _, spellId)
  -- журнал боя: event, timestamp, subevent, srcGUID, srcName, srcFlags, dstGUID, dstName, dstFlags, spellId, ...
  if sub == "SPELL_DAMAGE" and spellId == 12345 and RM.InRaid(dstName) then
    return dstName, "попал под заклинание"
  end
end
```

- **События** — через запятую: любые события WoW, `COMBAT_LOG_EVENT_UNFILTERED`, а также `RM_START`
  (начало боя, ключ босса), `RM_END` (конец: ключ, `kill` или `wipe`), `RM_SKADA` (после убийства: бой Skada).
- **`RM`**: `Fire(имя, текст)` — поставить сейчас; `After(сек, функция)` — позже в этом бою;
  `Role`, `Class`, `InRaid`, `Players`, `Unit`, `NpcId`, `Owner`, `Is(x, 1, 2, …)`, `Time`, `FightTime`,
  `Boss`, `Short`, `Test`; Skada: `SkadaPlayers`, `SkadaDamage`, `SkadaTime`, `SkadaTargets`, `SkadaEnemies`.
- **`fight`** — таблица на бой (очищается на пуле).
- Компиляция — `loadstring("local RM, fight = ...; return " .. код)` в `pcall`, без `setfenv`. Ошибка —
  строка в чат, текст в редакторе, правило молчит до конца боя. «Проверить код» — синтаксис без боя.
- Чужой свод (строка `RM2:`) с правилами «свой код» приходит с **выключенными** триггерами.
- Поле кода в игре удваивает «|» (как в WeakAuras) — аддон хранит обычный текст.

## Шаблоны (кнопка «+ Шаблон»)

Бывшие встроенные автоправила 0.1–0.3. Своды до 0.4.0 переносятся сами: автоправило → правило с этим
триггером (выключенным), числа РЛа подставляются в текст и в код; «дыхание или кольцо» — два правила.

| Раздел | Правило | Триггер |
|---|---|---|
| Ребро | Смерть от клива (не танк) | Смерть: 69055, 70814, 71021; роль — не танк |
| Ребро | Стоял в холодном пламени дольше N сек | Журнал боя: урон 69146, 70823–70825, серия N сек (3) |
| Леди | Дух догнал игрока | Неудача: Fail_Deathwhisper_Shade, каждый раз |
| Леди | Под МК убил своего | Смерть, виноват убийца, каждый раз |
| Леди | Под МК с оружием (мдд и охотники) | Свой код: МК 71289 и надето оружие |
| Орк | Планка ДПС: меньше N | Skada: ДПС < N (17к), роль мдд/рдд |
| Тухлопуз | Смерть от гнили | Смерть: 69195, 71219, 73031, 73032 |
| Гниломорд | Смерть в луже | Смерть: 69774, 69776, 69778, 71208 |
| Гниломорд | Заблевал милишников (гер.) | Свой код: газ 72272/72273 лёг на не-мили и задел мили |
| Проф | Смерть от чумы / пельменя / колбы | Смерть: чума, взрыв слизи, Податливая слизь |
| Проф | Бонус: урон в Профа и слизней (+10) | Свой код на RM_SKADA, оба порога (2,5М и 650к) |
| Принцы | Смерть от апельсина | Смерть: 71393, 72789–72791 |
| Лана | Лужа в рейд (носитель метки) | Свой код: лужа носителя задела N других (2) |
| Синдра | Смерть от ледяной бомбы | Смерть: 69845, 71053–71055 |
| Синдра | Смерть от дыхания (не танк) | Смерть: 69649, 71056–71058, 73061–73064; роль — не танк |

| Общие | Пул раньше таймера | DBM: раньше на 1 сек и больше, каждый раз |
| Общие | Воин без раскола в начале боя (N сек) | Свой код на RM_START + журнал боя: нет Раскола за N сек (10); кроме Кораблей и Валитрии |

Номера способностей — по LibFail и базам 3.3.5, их надо сверить на Circle. Аддон записывает способности
врагов в бою с боссом (`RaidMinusDB.spellLog`); в редакторе — кнопка «Из боя» у поля «Заклинание».

## Идеи для своих триггеров

Справочник: что видно в журнале боя (из разбора 0.1). (LF) — есть неудача LibFail, проще всего тип
«Неудача (Skada)». 🟥 — виноватый очевиден; 🟧 — виноватых назначает правило (например, «всем
охотникам» — свой код); 🟨 — вина не очевидна, лучше ставить вручную; ⬜ — в журнале боя этого нет.


### Лорд Ребрад
- 🟥 Смерть от клива, кроме танков — 69055, 70814, 71021 (LF).
- 🟥 Попал под клив, не будучи танком (по основной роли) — те же ID, своё правило.
- 🟥 Смерть от Вихря костей — 69075, 70834–70836 (LF).
- 🟥 Стоял в Холодном пламени дольше 2 сек — 69146, 70823–70825 (LF).
- 🟧 Смерть на костяном шипе → «не разбили шип»: вся зона РДД.
- ⬜ Растяжка, «охотник не зашёл в мили», «не отдали БОП».

### Леди Смертный Шёпот
- 🟥 Дух догнал игрока — удар Мстительного духа (NPC 38222) по цели (LF).
- 🟥 Смерть от взрыва духа — 71544, 72010–72012 (LF).
- 🟥 Стоял в Смерти и разложении дольше 3 сек — 71001, 72108–72110 (LF).
- 🟥 Урон по своим под МК (Подчинение разума, 71289): больше X ДПС или убил кого-то.
- 🟨 Игрок под МК N сек без контроля (страх, превращение, смерч, ослепление) — виноваты те, кто
  должен контролить.
- 🟧 Проклятие (71237) висит дольше N сек → рДру и рШаманы.
- ⬜ «Не снял оружие»: удар без оружия от удара с оружием не отличить.

### Битва на кораблях
- 🟥 Смерть во время боя — любая.
- 🟥 Смерть от взрыва — 69680, 69687; отброс на гер. — 69688, 69689 (LF).

### Саурфанг
- 🟥 Планка ДПС по Skada — только у основной роли МДД/РДД. Хил, переодетый в ДД, не считается.
- 🟥 Допуски к категориям (13к / 12к) — по той же цифре Skada.
- 🟥 Точечный урон по Кровавым тварям (NPC 38508) способностью не из белого списка. Белый список
  по классам — из правил РЛа.
- 🟨 Тварь ударила игрока — 38508 melee (LF).
- ⬜ «Сдвинулся с места».

### Тухлопуз
- 🟥 Смерть от Острой гнили (не взял спору) — 71219, 69195 (LF).
- 🟥 Гер.: попадание Податливой слизи больше 10к — 72549, 72550 (LF).
- 🟨 Заблевал милишников. Газ ложится на конкретного игрока, известно, на кого. Задел мили —
  виноват он (если он не мили).
- ⬜ «Глупая смерть».

### Гниломорд
- 🟥 Стоял в луже дольше 3 сек или умер в ней — 69774, 69776, 69778, 71208 (LF).
- 🟥 Пельмень: попал под взрыв большого слизня — 69832, 69833, 69839, 71209 (LF).
- 🟥 Струя слизи по не-танку дольше 3 сек — 69507, 71213, 73189, 73190 (LF).
- 🟨 Гер.: заблёв мили — как на Тухлопузе.

### Профессор Мерзоцид

### Общие
- 🟥 Пул раньше таймера: DBM-таймер + кто первым ударил босса. Если босса стянули телом — 🟨.
- 🟥 Воин не сделал ни одного Раскола брони по боссу за первые N сек.
- 🟥 Любая смерть — для правил вида «умер = минус».
- 🟥 Вайп — факт по DBM.
- 🟨 «Вайп по вашей вине»: аддон показывает последние смерти перед вайпом.
- 🟨 АФК без одобрения: мало активности по Skada.
- ⬜ «Нет бафа по просьбе», «напул не в того танка», «не отдали БОП».
